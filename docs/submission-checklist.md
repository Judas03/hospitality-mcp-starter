# Final submission checklist

- [ ] Devpost project has both teammates listed.
- [ ] GitHub repository is public with an open-source license, or private with Amazon and Devpost reviewers added.
- [ ] MCP server uses Streamable HTTP.
- [ ] Code actually imports and calls the MCP implementation.
- [ ] Browser demo sends initialize, tools/list, and tools/call.
- [ ] At least one complete booking flow works end to end.
- [ ] Conflict, modification, and cancellation are demonstrated.
- [ ] No API keys, credentials, or real customer data are committed.
- [ ] README works from a clean checkout.
- [ ] Demo video is public, in English, and under three minutes.
- [ ] Product feedback covers every API, SDK, and tool used.
- [ ] Any pre-existing code is clearly described as updated during the hackathon.
